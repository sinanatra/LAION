# LAION Explorer — app

A client-side gallery for browsing the sample built by [`../notebook/run_pipeline.py`](../notebook/run_pipeline.py). Svelte 5 + Tailwind CSS, built with Vite.

## Data it expects

- `public/data/metadata.json` — array of `{ id, filename, caption, source_url, keyword?, similarity?, x?, y? }` (`keyword` and `similarity` are optional — the pipeline samples systematically rather than by category; `x`/`y` are UMAP coordinates, present once the embeddings step has run)
- `public/data/images/{filename}` — the images referenced above

Both are generated by the pipeline script — see the top-level [README](../README.md) for the full workflow. Until it's been run, `metadata.json` is an empty array and the gallery shows no images.

## Running

```bash
npm install
npm run dev      # dev server with hot reload
npm run build    # static build in dist/, works fully offline
npm run preview  # serve the built dist/ locally
```

No backend, no external API calls — everything runs from the local `public/data/` files.
